# 四、偏差原因總結

本次開發整體預估時間為 60 小時，實際投入約 61 小時，總偏差：

```text
61 - 60 = +1 小時
```

主要偏差原因：

## 1. 前端整合時間增加

原先預估前端展示功能較簡單，但實際開發時需要處理：

- 搜尋結果展示
- 詳細資料載入
- ECharts 圖表初始化
- 圖表互動搜尋
- 前後端資料格式一致性

因此 PSP-06 增加約 2 小時。

---

## 2. 資料分析功能需要額外調整

關鍵詞統計與關聯圖需要：

- 處理論文標題資料
- 過濾低頻關鍵詞
- 降低圖譜節點數量
- 避免前端渲染卡頓

因此 PSP-08、PSP-09 有額外時間投入。

---

## 3. 文件整理時間增加

除了程式開發外，需要完成：

- README
- NABCD
- PSP
- Figma 原型文件
- AI 協作紀錄

因此 PSP-12 比預期增加時間。

---

## 4. CRUD 開發時間低於預期

CRUD API 架構較明確：

- POST 新增論文
- PUT 修改論文
- DELETE 刪除論文

使用 Flask 路由即可完成，因此實際時間少於預估。
