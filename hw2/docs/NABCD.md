# 頂會熱詞統計系統 NABCD 需求分析

## 文件說明

本文件針對「與 AI 結對編程（頂會熱詞統計）」作業，整理目前專案的需求、解決方式、預期效益、替代方案與交付方式。內容以目前程式、資料檔案及可實際確認的功能為依據，不將尚未完成的工作描述為已完成。

目前專案採用以下狀態標示：

- **已完成**：目前已有程式或資料，並可在本機展示或呼叫。
- **部分完成**：已有初步版本，但資料範圍、功能完整度或驗收仍不足。
- **未完成**：目前尚未建立，後續仍需設計與實作。

目前資料範圍主要是 CVPR 2024 論文。canonical 論文資料共有 2715 篇，其中 50 篇已有詳細欄位；趨勢資料包含 CVPR 與 ICCV 的 2022–2024 初步資料，不能視為完整的跨會議資料集。

## 1. N — Need：使用者需求與現有問題

### 1.1 目標使用者

本系統的目標使用者包括：

- 想快速瀏覽電腦視覺研究方向的學生。
- 需要整理頂級會議論文的研究者或課程學習者。
- 想觀察熱門詞彙、詞彙共現關係及初步趨勢的使用者。
- 需要展示資料爬取、後端 API、前端視覺化與 Git 開發流程的課程評閱者。

以上是依照作業目標與系統功能所定義的目標使用者，不代表已完成正式使用者訪談，也不代表已有實際使用人數統計。

### 1.2 使用者可能遇到的問題

頂會論文資訊通常分散在不同網頁或資料檔案中。使用者若只依靠人工瀏覽，可能遇到以下問題：

1. 論文數量較多，逐篇閱讀標題與連結需要較多時間。
2. 僅靠一般關鍵字搜尋，不容易快速整理整批論文中常見的研究詞彙。
3. 關鍵詞之間可能存在共同出現關係，但單純的列表不容易觀察。
4. 不同年份的熱詞變化需要額外整理資料與繪製圖表。
5. 論文詳細資料尚未全部取得，部分資料仍需要由原始論文頁面補充。

## 2. A — Approach：系統採取的解決方式

### 2.1 整體架構

目前採用 Flask + HTML/CSS/JavaScript + JSON 的輕量架構：

- **資料層**：使用 `data/papers.json` 作為搜尋、詳細資料、分析與 CRUD 共用的 2715 篇 canonical 論文資料；`data_cvpr2024.json` 與 `cvpr2024_detail.json` 保留為原始資料；使用 `data/trend_data.json` 保存趨勢長表。
- **後端層**：使用 Flask 提供搜尋、詳細資料、熱門方向、關鍵詞關聯圖與趨勢資料 API。
- **前端層**：使用 HTML、CSS、JavaScript 建立搜尋與分析頁面，並使用 ECharts 呈現關鍵詞圖譜及趨勢圖。
- **啟動方式**：目前以本機 Flask 服務提供 API，前端透過 API 取得資料後展示。

### 2.2 論文資料取得與管理方式

目前先取得 CVPR 2024 論文列表，再以獨立工具逐步取得部分論文詳細資料。詳細資料爬取工具已加入批次處理、失敗重試、斷點續爬及進度輸出等機制，降低一次執行失敗造成資料遺失的風險。

目前實際狀態如下：

- 論文列表：2715 篇。
- 詳細資料：50 篇測試及初步資料。
- 完整 2715 篇詳細資料：尚未完成。
- 論文新增、刪除、修改：已完成 JSON 層 CRUD 與 API 驗證；尚未加入資料庫交易與多人並行控制。

### 2.3 搜尋與詳細資料查詢

後端目前提供：

- `/search?q=keyword`：搜尋論文資料。
- `/paper/<title>`：依論文標題查詢詳細資料。

搜尋功能沿用 JSON 架構，不另外加入資料庫。搜尋範圍已擴充至 title、authors、year 與 conference，但 authors、year、conference 的有效範圍受限於目前只有 50 篇詳細資料。

### 2.4 熱門方向與關鍵詞分析

熱門方向分析目前以論文標題為主要輸入，將標題轉為小寫英文與數字詞，套用停用詞規則，再統計詞彙出現次數，產生 Top 10 結果。這種方法容易理解及在本機執行，但不能完全代表論文摘要或全文的研究語意。

關鍵詞關聯圖的處理方式為：

1. 從每篇論文標題擷取關鍵詞。
2. 同一篇論文內相同關鍵詞只計算一次。
3. 將同一篇論文共同出現的兩個關鍵詞建立一條邊。
4. 以共同出現的論文數量作為關聯強度。
5. 回傳節點的詞頻及節點之間的連線，交由前端圖表展示。

### 2.5 趨勢分析

目前趨勢分析使用預先整理的 JSON 長表。後端 `/trend` 會依會議、年份與 keyword 聚合並限制 Top N，前端直接使用聚合後的 series 呈現折線圖。趨勢資料仍未涵蓋 ECCV 與完整多年資料，因此目前不宣稱已完成完整跨會議分析。

### 2.6 尚未採用的處理方式

以下工作不屬於目前已完成的架構：

- 尚未加入資料庫。
- 尚未加入資料庫交易、權限控制與多人並行寫入處理。
- 尚未使用大型 AI 模型進行語意分類。
- 尚未建立可提交的專用原型工具作品。
- 尚未完成華為雲部署。

## 3. B — Benefit：系統可以帶來的效益

### 3.1 對使用者的預期效益

在目前資料範圍內，本系統可以提供以下協助：

1. **集中查詢**：使用者可以在同一個網頁介面搜尋 CVPR 2024 論文，而不必先手動整理列表檔案。
2. **快速查看資訊**：對已有詳細資料的論文，可以查看作者、年份、會議、PDF 及原文連結。
3. **初步掌握熱門詞彙**：透過 Top 10 統計，快速了解論文標題中較常出現的詞彙。
4. **觀察詞彙關聯**：透過關鍵詞關聯圖，查看哪些詞彙常在同一篇論文中出現，並進一步查詢相關論文。
5. **支援初步趨勢觀察**：透過折線圖查看測試資料中的年份變化。
6. **方便課程展示**：以 Flask API、JSON 資料與前端圖表組成，可展示從資料處理到 Web 呈現的完整開發流程。

### 3.2 對開發與學習的效益

此架構的元件較少，適合逐步加入功能，並可讓開發者分別練習：

- API 設計與前後端串接。
- 爬蟲的重試與斷點續爬。
- JSON 資料整理與分析。
- 關鍵詞統計及圖表視覺化。
- Git 分支、文件與 PSP 紀錄。

### 3.3 效益的驗證限制

目前沒有正式使用者訪談、實際使用人數、操作時間比較或準確率測試，因此本節只描述系統可提供的功能性效益，不宣稱具體效益數據。後續應透過測試案例、展示流程及人工檢查結果驗證功能是否符合需求。

## 4. C — Competitors：現有替代方案與本系統差異

### 4.1 人工瀏覽論文網站

使用者可以直接瀏覽 CVPR 或其他論文網站，取得較完整的原始資訊。

- **優點**：資料來源直接，通常適合查看單篇論文的完整內容。
- **缺點**：需要自行整理大量論文，較難直接取得本專案所需的 Top 10、關聯圖及趨勢比較。
- **本系統差異**：將目前收集的資料集中到本機 JSON，提供搜尋及初步分析；但不能取代原始論文網站，也不保證資料完整性高於原始來源。

### 4.2 一般學術搜尋引擎

使用者可以使用 Google Scholar、Semantic Scholar 或其他學術搜尋服務查找論文。

- **優點**：通常涵蓋多種來源，適合查找單篇或跨主題論文。
- **缺點**：搜尋結果、欄位與分析方式由服務平台決定，未必直接提供本作業要求的特定會議、詞彙共現與自訂趨勢分析；實際可用功能也可能受到網路、服務政策或存取限制影響。
- **本系統差異**：分析規則由開發者自行定義，結果較容易說明與重現，但資料範圍目前較小，且尚未涵蓋完整多會議資料。

### 4.3 試算表或人工統計

使用者也可以把論文標題複製到試算表，再自行統計詞彙。

- **優點**：不需要建立 Web 系統，初期上手容易。
- **缺點**：資料清理、同義詞處理、共同出現統計及圖表更新容易依賴人工，重複執行與維護成本較高。
- **本系統差異**：以程式固定資料處理與統計流程，並提供 API 及互動圖表；但目前分析仍是基本字詞處理，尚未解決同義詞與語意判斷問題。

### 4.4 本系統的定位

本系統是針對軟體工程課程作業所建立的可操作原型與分析工具，重點在於展示資料取得、API、前端互動及可重現的統計方法。它不是完整的學術資料庫，也不是現有學術搜尋服務的替代品。其主要差異是：在有限的本機資料範圍內，將論文搜尋、詞彙統計、關聯圖及初步趨勢整合到同一個 Web 介面。

## 5. D — Delivery：系統交付、展示與使用方式

### 5.1 目前可交付的本機版本

目前可以交付並展示的內容包括：

- Flask 後端 API。
- HTML/CSS/JavaScript 前端頁面。
- CVPR 2024 論文列表 JSON。
- 部分論文詳細資料 JSON。
- Top 10 熱門方向資料。
- 關鍵詞關聯圖資料及前端圖表。
- 初步趨勢資料及前端圖表。

目前的本機使用方式為：

1. 在專案根目錄啟動 Flask 後端：

   ```powershell
   .\.venv\Scripts\python.exe backend\api.py
   ```

2. 開啟前端的 `frontend/index.html`。
3. 使用搜尋欄查詢論文，或查看熱門方向、關鍵詞關聯圖與趨勢圖。
4. 對搜尋結果按下詳細資料功能，查看已有資料的論文資訊。

目前服務預設使用本機位址 `http://127.0.0.1:5000`。前端圖表使用 ECharts，實際載入是否受到外部 CDN 或目前網路環境影響，仍需要在使用環境中驗證。

### 5.2 目前 API 展示項目

| `GET /paper/<title>` | 查詢單篇論文詳細資料 | 已完成，可查詢 canonical 論文；完整作者、PDF 等欄位目前主要限於既有 50 篇資料 |

### 5.3 課程展示時的建議流程

展示時可以依序說明：

1. 開啟首頁並確認 Flask 服務正常。
2. 搜尋 `diffusion` 等關鍵字，展示搜尋結果。
3. 開啟一篇已有詳細資料的論文，展示作者、年份、會議、PDF 與原文連結。
4. 展示 Top 10 熱門方向。
5. 展示關鍵詞關聯圖，點擊節點查看相關論文。
6. 展示初步趨勢圖，說明目前資料範圍與限制。
7. 說明資料爬取、API、前端及分析模組之間的關係。

### 5.4 尚未完成的交付項目

- 使用專用原型工具製作的正式原型。

### 5.5 目前限制與後續交付方向

目前系統的主要限制如下：

1. 論文詳細資料只有 50 篇，無法代表全部 2715 篇的完整欄位。
2. Top 10 與關聯圖主要根據標題文字統計，沒有使用摘要、全文或語意模型。
3. 尚未處理完整的同義詞、縮寫、複合詞及不同寫法正規化。
4. 趨勢資料仍是初步資料，尚未完成 ICCV、ECCV 與足夠年份的比較。
5. 目前沒有資料庫交易、權限控制與完整並行寫入保護；資料更新主要依賴 JSON 與爬取工具。
6. 目前以本機環境展示，尚未驗證華為雲部署、外部服務連線及正式的多人使用情況。

後續交付可依序完成資料擴充、ECCV 與更多年份趨勢、華為雲部署及正式 Release；每項工作都應在實際測試後更新文件，不應只以規劃內容代替完成證據。
